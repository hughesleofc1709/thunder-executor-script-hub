## Overview

Thunder Executor is a Windows desktop Roblox script executor for working with Lua scripts through a straightforward interface. Its design keeps the application compact while providing direct execution controls and an integrated hub for collecting and accessing commonly used Roblox scripts.

Version 3.4 is intended for Windows 10 and Windows 11 users seeking a practical Lua execution companion. It includes grouped execution, a queue that remains available between runs, automatic update support, and a user interface that can be displayed in multiple languages.

## Frequently Asked Questions

**Which operating systems can run Thunder Executor?**  
The current release is intended for computers running Windows 10 or Windows 11.

**Can an older build remain compatible after a Roblox update?**  
Roblox client and script changes may affect compatibility. In some cases, the executor version must correspond with the current Roblox release.

**What does Thunder Executor provide beyond a standard script hub?**  
It brings script execution, hub browsing, grouped execution, and debugging tools together in one lightweight Windows application.

**Can using a script executor impact my Roblox account?**  
Use of the software is subject to Roblox rules and remains the user's responsibility. Account results depend on usage and any enforcement applied by the platform.

**Does the application save scripts on the computer?**  
Depending on the build and how it is used, script information and local preferences may be stored on the device.
